## Troubleshooting Common Issues

Install issues? Check the export options when hierarchy is flattened in the output.  
Performance problems? Trim branches before pitch mode rather than during a presentation.  
License/activation? Reinstall if themes fail to load after an update.  
Compatibility? Keep a local copy before converting a map to a new template.  
Update failures? Verify notes are attached to the correct topics before export.
